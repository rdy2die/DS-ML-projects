# ЛР №1 «Знакомство с Python»

Консольная программа для расчёта статистических метрик набора данных
о демографии регионов России.

Используется только стандартная библиотека Python 3 (`csv`, `math`, `os`,
`sys`, `difflib`). Сторонние пакеты не требуются.

## Запуск

```bash
python main.py                            # путь к файлу спросит программа
python main.py russian_demography.csv     # путь можно передать аргументом
```

## Как работает

1. Программа читает CSV-файл и сообщает, сколько строк и колонок загружено.
2. Пользователь вводит название региона (по `?` выводится список всех 85).
3. Печатается таблица всех колонок по выбранному региону.
4. Пользователь выбирает ID колонки для расчёта метрик.
5. Выводятся максимум, минимум, медиана и среднее значение.
6. Выводится таблица перцентилей от 0 до 100 с шагом 5.
7. Можно повторить расчёт для другого региона или колонки.

## Архитектура

Приложение разделено на компоненты, как требует задание.

| Файл | Слой | Ответственность |
|---|---|---|
| `stats.py` | логика | фильтрация, метрики, перцентили. Не делает ввод-вывод |
| `csv_reader.py` | ввод-вывод | чтение и разбор CSV-файла |
| `user_input.py` | ввод-вывод | диалог с пользователем, проверка формата ввода |
| `console_output.py` | ввод-вывод | форматирование и печать таблиц |
| `main.py` | точка входа | связывает компоненты, ловит ошибки верхнего уровня |

Компонент логики (`stats.py`) не импортирует ни один модуль ввода-вывода,
поэтому его можно использовать с любым интерфейсом — консольным,
графическим или веб. Об ошибках он сообщает через `ValueError` с текстом
на русском языке, а решение о том, как показать ошибку, принимает
вызывающий код.

## Расчёт перцентилей

Используется метод ближайшего ранга, точно соответствующий определению из
задания: N-й перцентиль — такое число X, что не менее N% элементов
выборки меньше либо равны X.

```
rank = ceil(N / 100 * len(values))
percentile = sorted(values)[max(rank, 1) - 1]
```

При таком подходе 0-й перцентиль равен минимуму, 100-й — максимуму,
а 50-й совпадает с медианой на выборках нечётной длины.

## Обработка ошибок

Программа не завершается аварийно ни в одном из сценариев: пользователю
выводится понятное сообщение с указанием конкретной причины, после чего
ввод повторяется.

**Файл**: путь не указан, файл не найден, указана папка, нет прав на
чтение, файл пуст или слишком велик, неизвестная кодировка, отсутствует
заголовок, пустые или повторяющиеся имена колонок, распознана одна
колонка (неверный разделитель), в строке неверное число значений, нет ни
одной строки данных, нет колонки `region`.

**Ввод пользователя**: пустое название региона, несуществующий регион
(с подсказкой похожих названий), пустой ID колонки, ID не является целым
числом, ID вне диапазона, выбрана текстовая колонка, нераспознанный
ответ на вопрос «да/нет».

**Данные**: пустые ячейки (пропускаются, их количество показывается
отдельной строкой), нечисловое значение в числовой колонке, отсутствие
заполненных значений по выбранному региону, значения `nan`/`inf`.

**Среда выполнения**: `Ctrl+C` (KeyboardInterrupt), `Ctrl+D` (EOFError),
нехватка памяти, ошибки операционной системы, а также перехват любых
непредвиденных исключений в `main()`.

## Соответствие принципам

- **KISS** — только функции, никаких лишних абстракций и классов.
- **DRY** — вывод всех таблиц идёт через одну функцию `format_table`,
  разбор чисел — через одну функцию `parse_number`.
- **YAGNI** — реализовано ровно то, что требует задание.
- **Code style** — Google Python Style Guide: докстроки с `Args`,
  `Returns`, `Raises`, длина строк до 80 символов, `snake_case`,
  приватные имена модуля с подчёркиванием, импорты в начале файла.
