# Тестовые файлы для проверки обработки ошибок

Запуск: `python3 main.py`, затем ввести путь до нужного файла из этой папки.

| Файл | Что проверяет | Ожидаемое поведение |
|---|---|---|
| `empty.csv` | пустой файл (0 байт) | «Файл пустой — в нём нет данных.» |
| `notcsv.txt` | неверное расширение | «Ожидается файл с расширением .csv.» |
| `no_region.csv` | нет обязательной колонки `region` | «В файле нет обязательной колонки 'region'.» |
| `header_only.csv` | только заголовок, ни одной строки | «Файл не содержит строк с данными.» |
| `cp1251.csv` | файл не в UTF-8 | «Файл не читается: ожидается кодировка UTF-8.» |
| `bom_region_first.csv` | UTF-8 с BOM, `region` — первая колонка | читается штатно (кодировка utf-8-sig) |
| `bad_values.csv` | часть значений нечисловые / пустые | «пропущено N некорректных значений», метрики считаются по остальным |
| `all_bad.csv` | все значения метрики нечисловые | «В колонке 'value' нет числовых данных», возврат к выбору |
| `short_row.csv` | строка короче заголовка | пустая ячейка в таблице, программа не падает |

Проверить вручную:

| Действие | Ожидаемое поведение |
|---|---|
| несуществующий путь | «Файл ... не найден» |
| путь до папки, а не файла | «... — это не файл» |
| пустой ввод пути (Enter) | «Путь до файла не может быть пустым.» |
| ввод `exit` на любом вопросе | «Работа программы завершена.» |
| Ctrl+D / Ctrl+C | «Работа программы завершена.», без traceback |
| номер вне диапазона (например `99`) | «номера 99 нет в списке. Допустимо от 1 до N» |
